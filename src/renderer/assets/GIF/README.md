# GIFs de célébration

Placez vos fichiers GIF de célébration dans ce dossier.

L'application sélectionnera automatiquement un GIF aléatoire parmi ceux disponibles dans ce dossier pour l'afficher sur la page de fin de process.

**Format requis :** `.gif`

**Taille recommandée :** 500x400px maximum pour un affichage optimal.
